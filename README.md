# Котики

Интерактивные сцены с котами для телефона. Всё нарисовано и озвучено кодом: canvas и Web Audio, ни одной картинки или звукового файла.

- [Кошка в сакуре](https://trag3ek.github.io/cats/cherry-cat/): веди пальцем, и кошка побежит следом. Палец на стволе — точит когти, тряска телефона — лепестки, семь быстрых тапов — прилетает ворона.
- [Коты в снегу](https://trag3ek.github.io/cats/snow-cats/): гладь кота, тяни за хвост, рисуй по снегу, стряхивай снег с зонтиков. Со звуком.
- [Кот и гроза](https://trag3ek.github.io/cats/storm-cat/): тап в небо — молния, погладь кота, чтобы не пушился, свайп вверх по коту — полетит. Со звуком.
- [Белый котёнок акварелью](https://trag3ek.github.io/cats/white-cat-watercolor/): следит за пальцем, гладь его и чеши подбородок, тап по носу — буп, поднеси палец ко рту — кусь. Долгое касание — зевает и засыпает. Мурчит.
- [Белый котёнок](https://trag3ek.github.io/cats/white-cat/): тот же котёнок, только объёмный. Ловит бабочку, чихает от лепестков, трясёт головой от тряски телефона.

Лучше всего на телефоне. Первый тап спросит доступ к датчикам движения (тряска и наклон).

Исходники живут в отдельном проекте; здесь лежат только собранные страницы.
